# Senhor Fix — site

Site da Senhor Fix, assistência especializada em celulares no Imperial Shopping, em Imperatriz (MA).

- `index.html`: página do site
- `css/estilo.css`: visual (cores, fontes, tamanhos)
- `js/config.js`: WhatsApp, mensagens e desconto do Pix
- `js/precos.js`: serviços, peças, modelos e preços
- `js/main.js`: lógica do orçamento
- `img/`: logo e ícones

Guia de edição: veja `LEIA-ME.md`.
